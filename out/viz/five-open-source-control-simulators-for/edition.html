Three free Python projects simulate an electric-vehicle battery management system, one simulates an electrolyser controller, and one turns muscle signals into prosthetic-hand commands. Each ran in its guide without hardware, and each says its results come from simulation or synthetic data, not a real device.

What it means: All three battery simulators pass the same 112 tests, and each guide reports its own run time.

What to do: Start with cell-guardian, since its guide is the newest and its tests ran fastest of the three.

The EMG decoder's 97.2% is on synthetic data; its README expects 75–90% for amputees

What it means: The 97.2% figure comes from synthetic demo data, so it overstates what a real user should expect.

What to do: Test the decoder on your own recorded CSV data before trusting any accuracy figure.

The scooter pack's simulated health falls from 90.0% to 70.0% over 300 cycles

What it means: The ageing model is a straight line, so it cannot predict the life of a specific real cell.

What to do: Use the degradation run only to teach how fade is modelled, not to estimate pack life.

Example 8 prints hydrogen output far above the spec in the same code

What it means: The electrolyser's production output is physically wrong, so its figures cannot be quoted.

What to do: Do not quote this repository's production numbers, and read its limitations before running any example.

Sources and caveats

This page replaces the five separate how-to guides this blog wrote for these tools, one per repository. Everything here is taken from those guides, which drew on each repository’s README, source and tests and on runs in throwaway environments: bms-battery-management on 18 October 2026, ev-battery-management-sim on 19 October 2026, hydrogen-electrolyser-control on 23 October 2026, bionic-limb-control on 5 November 2026 and cell-guardian on 6 November 2026. Where the battery guides differ, the newest (cell-guardian) is preferred. All results are from simulation or synthetic data. Repositories: github.com/herrrickshaw/cell-guardian; github.com/herrrickshaw/ev-battery-management-sim; github.com/herrrickshaw/bms-battery-management; github.com/herrrickshaw/hydrogen-electrolyser-control; github.com/herrrickshaw/bionic-limb-control.
