Source: MoSPI API via the MoSPI MCP tools (list_datasets, get_indicators, get_metadata, get_data), pulled on 26 Oct 2026.
"YoY (API)" means the API returned the rate directly. "YoY (computed)" means I worked it out from index levels in the same base: (index_t / index_t-12 - 1) x 100.

## Base-year warning (read before reusing old posts)

Several core series moved to a new base in 2026. Older posts may quote old-base numbers, which cannot be compared directly with these.

| Series | New base (used here) | Old base often cited | Note |
|---|---|---|---|
| CPI (all-India, MoSPI) | **2024=100** | 2012=100 | New COICOP-style structure (division/class/sub-class). Series runs from Jan 2025. **All India is state_code=1 in base 2024**, not 99. |
| WPI | **2022-23=100** | 2011-12=100 | Data from 2023. The API gives index levels only, so YoY is computed. |
| IIP | **2022-23=100** | 2011-12=100 | New sub-sectors, such as renewable and non-renewable electricity. |
| NAS (GDP/GVA) | **2022-23** | 2011-12 | Only the Current series exists in the new base. Growth rates were revised, e.g. FY24 is 7.3% in the new base. |
| ISP (services index) | 2024-25=100 | (new series) | New monthly services index. |
| CPI-AL/RL (Labour Bureau) | 2019=100 | 1986-87=100 | Not a 2026 change, but older posts may use 1986-87. |

## Gotchas for future pulls

- **CPI base 2024**:
  - All India is `state_code=1`, while base 2012 uses 99.
  - Pass `division_code=0` for the General index.
  - A division filter returns the division plus all its groups, classes and sub-classes (657 rows for Food). Use `sector_code` and `month_code` to narrow it.
- **WPI**: no inflation field is returned. Compute YoY from same-month index levels. Filtering by a major group returns all of its descendants.
- **NAS 2022-23**: request indicators one at a time. A comma list with Annually gave a 500.
- **PLFS**: `indicator_code` takes a single value only. Monthly data is All India only.
- **ISP**: there is no General index in the API. month_code follows the FY (4 = July).
- **RBI via MoSPI**: lags by more than a year (latest mid-2025).
