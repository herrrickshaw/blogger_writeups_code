What it is for

This toolkit gives a first, traceable estimate of how much compressed biogas (CBG) a plant makes from a given feedstock. It covers feedstock, anaerobic digestion (Buswell equation), upgrading to the IS 16087 gas standard, multistage compression to 250 bar and the digestate left over.

The demo checks the model against Barsana Phase I, a published plant that takes in 225 tonnes a day and makes about 10 tonnes a day of CBG.

Who it is for

  • Students and analysts who want to understand how CBG plants are sized
  • Project developers doing an early feasibility sketch
  • Engineers who want a transparent, literature-based starting point
Not for.
  • Detailed engineering design, equipment purchase or bank-grade feasibility
  • Anything needing vendor data; the repo uses literature correlations only

Install

  1. Make sure Python 3.10 or newer is installed
    python3 --version
  2. Create and activate a virtual environment (keeps the install tidy)
    python3 -m venv .venv && source .venv/bin/activate
  3. Install the package with the test tools. The dependencies (CoolProp, pandas, plotly, streamlit or scipy/numpy) come in automatically from pyproject.toml.
    pip install -e ".[dev]"

Quick start: commands and what you should see

Run the test suite to confirm everything works on your machine

pytest -q

A row of dots ending in 32 passed (about 8 seconds in the demo).

Run the full chain at Barsana scale (225 t/day of feedstock)

python examples/full_chain_worked_example.py

A table of CBG output for dung/straw splits from 0% to 100% dung, from 29.31 t/day (all straw) down to 10.14 t/day (all dung), then a 50/50 detail: 49,102 Nm3/day raw biogas at 50.4% CH4, upgrading to 98.0% CH4 that meets IS 16087, about 583 kW, 4-stage compression to 250 bar at about 277 kW, and 609 m3/day of digestate.

Optional: start the interactive app

streamlit run streamlit_app.py

A local web page opens in your browser. This step is in the README; it was not part of the captured demo run.

Sample prompts for your AI assistant

Copy, paste and edit the parts in [brackets].

  • Explain this repository in plain English: what does it size, what goes in and what comes out?
  • Run the tests and the worked example, then summarise the results in a short table.
  • Show me how the CBG output changes when I change the dung and straw split, and explain why.
  • Open docs/VALIDATION.md and tell me where this model matches published figures and where it does not.
  • What would I need from a vendor or a licensed simulator before I could rely on these numbers?
  • Change the plant size to [your tonnes per day] and show me which outputs change most.

Limits and honest caveats

  • Conceptual sizing, not detailed engineering design.
  • Only a 100% dung feed lands near the published plant (10.14 vs 10 t/day). Every mix that includes straw overshoots, up to 29.31 t/day for pure straw.
  • Straw's calibrated gas yield is about 3x dung's. Barsana's real feedstock mix is not public, so this gap is unresolved.
  • The model uses literature correlations only, with no vendor data.
  • Run it as a sanity check, not as a guarantee of what a real plant will produce.
