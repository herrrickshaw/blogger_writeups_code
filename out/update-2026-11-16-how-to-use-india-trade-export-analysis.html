Why it is useful

  • Who benefits: students and trade analysts who want a ready commodity-level export table (HS code, 2020 value, 2023 value, growth) without downloading TradeStat themselves.
  • What it replaces: the first day of cleaning TradeStat spreadsheets. The results are already in CSV and JSON.
  • Evidence from our run: we loaded the committed 14,980-row CSV in pandas and recovered the headline totals, US$291.8 bn in 2020 and US$437.7 bn in 2023.
  • Evidence of limits: the line items sum to US$460.5 bn, about 5% more than the total row, so the table is not a clean partition of exports.
  • The scripts need raw TradeStat Excel files that are not in the repository, so they could not be re-run.

What it is for

The repo's Python scripts read TradeStat Excel exports, compute growth between 2020 and 2023, project 2025 and 2026 by extending that growth, and classify commodities as mega-growth, high-value growing or emerging opportunity. Markdown write-ups discuss reserves, tax and debt. The README describes it as indicative analysis from public sources, not official statistics.

This guide shows how to explore the committed outputs. It is trade analysis for learning, not investment or business advice. The repository is archived (read-only).

Who it is for

  • Students of international trade and Indian export structure
  • Analysts who want a starting commodity table to verify against the official source
  • Anyone learning how a growth-and-projection screen is built, and where it breaks
Not for.
  • Investment or trading decisions
  • Citing the 2025-2026 projections: they extend one historical growth rate
  • Treating the 'opportunity' shortlist as a recommendation without checking classification changes

Install

  1. Get the code
    git clone https://github.com/herrrickshaw/india-trade-export-analysis.git
cd india-trade-export-analysis
  2. Make a virtual environment and install pandas
    python3 -m venv .venv
.venv/bin/pip install pandas

Quick start: commands and what you should see

Load the extended table and read the totals

.venv/bin/python -c "import pandas as pd; d=pd.read_csv('EXTENDED_ANALYSIS_2020_2026.csv'); print(d.shape); print(d.iloc[0])"

14,980 rows and 7 columns; the first row is India's total export with values for 2020 and 2023 in US$ million.

Count the opportunity classes

.venv/bin/python -c "import pandas as pd; print(pd.read_csv('HIGH_OPPORTUNITY_EXPORTS.csv').Opportunity.value_counts())"

Three classes with 246, 41 and 6 commodities.

Run a script (needs raw data)

.venv/bin/python export_opportunities.py

Without the TradeStat workbooks and Downloads folder it cannot run. We did not run it.

Limits and honest caveats

  • Scripts depend on raw TradeStat workbooks and hard-coded personal Downloads paths that are not in the repository; we could not re-run them.
  • Line items sum to US$460.5 bn against a US$437.7 bn total row (5% gap).
  • Projections to 2025 and 2026 repeat the 2020-2023 growth rate (the total row shows the same 50.0% again), so they are extrapolation, not a forecast.
  • Growth labelled 5-year covers 2020 to 2023; very large percentages come from small bases.
  • Indicative analysis from public sources, not official statistics, not investment advice. The repository is archived.
