One Python file that fetches settled closes for 15 Indian and 15 US large caps from yfinance, computes day change, 50/200-day cross and a Darvas box signal, and writes a self-contained HTML brief. No cache, no state, and a missing price is never treated as zero.

Why it is useful

  • Retail investors and students who follow a small set of large caps get a daily answer to 'did anything happen?' in one HTML file, with the bar date printed next to every price.
  • It replaces fragile multi-source pipelines with one file and one data source (yfinance), pinned dependencies, and failure rules written down: a failed market is named in the output, and if nothing fetches the script exits non-zero instead of sending an empty brief.
  • Evidence from the run: the offline self-test passed 12 checks, including 'a NaN final close is NO_DATA, not a fabricated zero', and the live run priced 30 of 30 tickers in about 7.6 seconds.
  • It is also a compact worked example of defensive design: no zero-filling, hardcoded universe, dates on every number.

What it is for

market-brief-base is the deliberately minimal floor beneath a larger pipeline. For 30 hardcoded large caps it reports the last settled close and its bar date, the day change, a 50/200-day moving-average cross label and a Darvas box state (IN_BOX, BREAKOUT_BUY, BREAKDOWN_SELL or NO_DATA), then renders HTML and can optionally email it.

The labels are mechanical screen states for research and education. They are not recommendations.

Who it is for

  • Self-directed investors who want a plain daily summary of a few large caps
  • Students learning Darvas boxes and moving-average crosses on real data
  • Developers who want a template for a reliable scheduled report
Not for.
  • Investment advice: this is not investment advice, and nothing here is a recommendation to buy or sell
  • Intraday or real-time prices: it uses settled daily bars
  • Broad coverage: it is hardcoded to 30 stocks and has no fundamentals, news or watchlist

Install

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/market-brief-base.git
cd market-brief-base
  2. Either let run.sh build the venv, or do it by hand
    ./run.sh --self-test
# or by hand:
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

Quick start: commands and what you should see

Verify the signal logic offline

python brief.py --self-test

A list of PASS lines ending with 'self-test: OK'. No network needed.

Produce today's brief

python brief.py --out brief.html

'India: 15/15 priced', 'US: 15/15 priced', then 'wrote brief.html'. Open the HTML in a browser.

Ways to use it

MethodHow it works
Run locally./run.sh writes brief.html; open it in a browser.
Schedule itThe repo includes a GitHub Actions workflow (weekdays 01:00 UTC) and a launchd plist; without email secrets the workflow uploads the brief as an artifact. Keep the repo private if you set email secrets.
Change the universeEdit the UNIVERSE dict at the top of brief.py (use exchange-qualified tickers such as .NS for NSE) and re-run the self-test.
Through an AI assistantOpen the folder in Claude Code or Gemini CLI and ask it to explain the Darvas logic or add a sector column, or upload brief.py to a chat assistant.

Limits and honest caveats

  • Educational and research only: this is not investment advice, and the labels are not buy or sell recommendations.
  • Data come from Yahoo Finance via yfinance, which can change or rate-limit; the script fails soft per market and exits non-zero if nothing fetches.
  • The Darvas label and the 50/200 cross measure different things, so combinations like BREAKOUT_BUY with Death Cross are normal in the output.
  • I ran it on Python 3.11 with the pinned versions; I did not test other Python versions against the pins.
  • I did not test email sending, GitHub Actions or the launchd plist. Never commit SMTP credentials; the README warns to use a new app password.
  • The brief reflects one day's settled bars (4-5 November 2026); your numbers will differ.
