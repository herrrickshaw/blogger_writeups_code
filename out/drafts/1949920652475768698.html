Why it is useful

  • Developers and students working on medical-imaging pipelines get a complete, readable end-to-end example: ingest, per-frame quality and flags, event grouping, report and highlight video.
  • It replaces building the plumbing yourself: a TCP receiver with sequence numbers and CRC32, frame-quality scores, redundancy filtering and a self-contained report are already there, and a hook is documented for adding a learned detector.
  • Evidence from my run: the synthetic study of 600 frames produced 2 bleeding and 2 lesion events, region boundaries with confidence 0.73, and a report.html, frames.csv, study.json and highlights.mp4 in about 3 seconds.
  • The thresholds were tuned on the synthetic generator, so the recovered events prove the plumbing works, not that it works on patients.

What it is for

capsule_cv screens a capsule endoscopy recording (video file, folder of frames, or a live TCP stream) with colour and texture heuristics: quality (brightness, blur, debris), suspected blood, compact pale or red lesion candidates, redundancy against the last kept frame, and a stomach / small bowel / colon segmentation. Flagged frames are grouped into episodes with a peak frame.

It is a research and decision-support sketch. It is not a medical device, is not validated on patient data and is not a diagnosis. This is not clinical advice.

Who it is for

  • Engineers and students prototyping medical video pipelines
  • Researchers who want a baseline and a report format before adding a deep model
  • Anyone teaching classical CV on a synthetic, ground-truth example
Not for.
  • Clinical use or diagnosis: not clinical advice; absence of a flag does not exclude pathology
  • Validating performance on patients: it has not been validated on patient data
  • Polyp or tumour detection: the README lists these as known gaps

Install

  1. Clone the repository
    git clone https://github.com/herrrickshaw/capsule-endoscopy-cv.git
cd capsule-endoscopy-cv
  2. Create an environment and install
    python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Quick start: commands and what you should see

Make a synthetic study and analyse it

.venv/bin/python -m capsule_cv synth --out synthetic/capsule.mp4
.venv/bin/python -m capsule_cv analyze synthetic/capsule.mp4 --out report

A JSON summary prints and report/ gains report.html, highlights.mp4, frames.csv and study.json.

Run the tests

.venv/bin/python -m pytest -q tests

8 passed.

Limits and honest caveats

  • Not clinical advice and not a medical device. Not validated on patient data; absence of a flag does not exclude pathology.
  • All numbers come from the built-in synthetic generator; thresholds were tuned on it. Re-tune on labelled real data (the README suggests Kvasir-Capsule) before trusting anything.
  • review_reduction_pct was only 24.2% on the synthetic study, so do not read it as typical.
  • No polyp or tumour detection and no deep model; region segmentation assumes the study reaches the colon.
  • I did not run the live receive/send path.
