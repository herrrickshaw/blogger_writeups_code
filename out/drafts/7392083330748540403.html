Why it is useful

  • Students, journalists and political-science researchers get a transparent worked example of cooperative game theory (Minimal Winning Coalitions, Banzhaf index) applied to seat arithmetic, with every script and result file in the repo.
  • It replaces opaque spreadsheet models with scripts and workbooks you can re-run, and an ASSUMPTIONS.md that lists each assumption, the evidence for and against it, and a test that enforces the verdict.
  • Evidence from the run: 45 tests passed and 18 strict expected-failures (assumptions the data contradicts) in 8 seconds, and the coalition script ran in under a second on the committed party_seats.csv.
  • The repo reports a negative result honestly: its vote-share models do not beat a naive 'no change' baseline on held-out elections.

What it is for

india-election-analysis has three parts: election-data-analysis (electors per constituency and the 2026 delimitation context), coalition-game-theory (Minimal Winning Coalitions, Banzhaf Power Index, six scenarios and a 20,000-draw Monte Carlo), and vote-share-modeling (constituency vote-share models on TCPD Lok Dhaba data, 1999-2019).

This post covers running the tests and the bloc-level coalition script. It is a methodological exercise in how seat arithmetic maps to bargaining power: the README states plainly that none of it is a forecast, and this post adds no political opinion.

Who it is for

  • Students of game theory and political science
  • Researchers who want a reproducible, auditable seat-arithmetic model
  • Data journalists explaining how coalition maths works
Not for.
  • Forecasting any election: the repo says the analyses are not forecasts
  • Concluding which party or bloc is better or worse: this post and the tool are descriptive
  • Individual-level analysis: only aggregate seat, party and constituency data are used

Install

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/india-election-analysis.git
cd india-election-analysis
  2. Create a virtual environment and install the dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install pandas numpy openpyxl scipy pytest

Quick start: commands and what you should see

Run the assumption-audit tests

python -m pytest -q tests

45 passed, 18 xfailed in about 8 seconds. The xfails are strict: each records an assumption the committed data contradicts.

Run the bloc-level coalition game on the committed seat table

cd coalition-game-theory/data
python ../scripts/02_bloc_level_game_theory.py

The bloc totals, 4,096 subsets enumerated, the minimal winning coalitions and the Banzhaf index. Note: the script reads party_seats.csv from the current folder, so run it from the data folder.

Limits and honest caveats

  • Not a forecast, and no political opinion is offered here: the analyses are structural exercises on seat arithmetic.
  • The repo's own audit finds assumptions the committed data contradicts (18 strict expected failures); read ASSUMPTIONS.md before quoting any headline number.
  • The vote-share models do not beat a naive baseline on held-out elections (stated negative result).
  • Run the coalition script from coalition-game-theory/data, because it opens party_seats.csv by relative path.
  • Raw TCPD files are not committed; derived files are. Credit: TCPD Indian Elections Data v2.0, Trivedi Centre for Political Data, Ashoka University (2021); TCPD does not endorse this analysis.
  • I ran the tests and the bloc-level script only; I did not rebuild the Excel workbooks or run the vote-share models.
