Why it is useful

  • Self-directed investors and students who want a free, readable example of a layered screen (price structure, then financial health, then compounder quality) get a script they can run and read.
  • It replaces opening several finance sites for one ticker: one command printed quote, valuation, dividends, earnings dates, 30-day summary and holders for MSFT.
  • Evidence from the run: the US daily report fetched and printed a full MSFT page in one command with only yfinance, pandas and openpyxl installed.
  • It also shows the cost of free data: my run found a wrong dividend yield and a screener that fell back to a five-stock sample with placeholder metrics.

What it is for

Claude Stock Tools is a collection of scripts. 01_daily_reports has one-ticker terminal reports for India, the US and Singapore. 02_market_screeners has full-exchange scanners that run Darvas Box detection, then Piotroski and Coffee Can scoring on breakout candidates, plus a Buffett-style value screener. Colab notebooks, a strategy reference and Damodaran enrichment sit in the other folders.

All prices and fundamentals come from Yahoo Finance via yfinance, so the scripts need network access and inherit its gaps.

Who it is for

  • Students learning Darvas, Piotroski and Coffee Can by reading working code
  • Self-directed investors who want a quick one-ticker research page
  • Developers who need a starting point for a multi-market scanner
Not for.
  • Investment advice: this is not investment advice, and nothing here is a recommendation to buy or sell
  • Unattended trading or alerts: the data is unofficial and sometimes wrong
  • Treating the Buffett screener output as meaningful without checking it (see the limits)

Install

  1. Clone the repository
    git clone https://github.com/herrrickshaw/claude-stock-tools.git
cd claude-stock-tools
  2. Create an environment and install dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install yfinance pandas openpyxl requests

Quick start: commands and what you should see

Print a one-ticker US report

python 01_daily_reports/us_daily_report.py MSFT

A terminal page with live quote and valuation, corporate actions and earnings calendar, 30-day summary, holders and news.

Run the Buffett value screener on a small US sample

python 02_market_screeners/buffett_value_screener.py --market us --limit 20

Logs the number of equities screened and saves an Excel workbook next to the script.

Limits and honest caveats

  • Not investment advice. These scripts are mechanical filters for research and education.
  • Bug found: the US report shows MSFT dividend yield as 75.00%. The script formats the yfinance dividendYield field as a fraction, but current yfinance already returns a percentage (0.75).
  • Bug found: the Buffett screener fell back to a 5-stock sample when the S&P 500 list could not be fetched, and its fundamental columns held placeholder values (ROE 0, gross margin 100), so it reported 0 picks.
  • Data comes from Yahoo Finance via yfinance, which is unofficial; verify anything interesting against filings. Annual fundamentals only.
  • I did not run the full-exchange scanners; they need many minutes of network calls and extra packages for India, Japan and Korea.
  • The insider-transaction section of the report lists named officers from public filings; I left that section out of this post.
