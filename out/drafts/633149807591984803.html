Why it is useful

  • Students and prototypers building myoelectric control get a compact, readable reference pipeline in one Python file, using the standard Hudgins feature set and LDA that the literature uses.
  • It replaces stitching together filters, windows, features and a classifier yourself, and it evaluates the honest way: it trains on early repetitions and tests on later ones, avoiding the leakage that inflates accuracy by 10-20 points in many EMG projects.
  • Evidence from my run: 97.2% window accuracy on later repetitions, and an online replay that agrees with the labels 88.2% of the time, with the gap explained by smoothing lag at gesture transitions.
  • The README also lists similar open-source projects and a suggested path to real hardware, with a safety reminder.

What it is for

emg_decoder.py is a reference pipeline for surface EMG from forearm muscles: 20-450 Hz Butterworth filter with mains notch, 200 ms windows with 50 ms step, time-domain features, StandardScaler plus LDA, a 5-window majority vote and proportional speed from normalised mean absolute value. It also includes a two-electrode direct control scheme (flexor closes, extensor opens, co-contraction cycles the grip) and a causal filter for streaming.

It is research and teaching code and is not a medical device. This is not clinical advice.

Who it is for

  • Students and hobbyists learning pattern-recognition prosthetic control
  • Researchers who want a leakage-free baseline to compare against
  • Makers connecting an EMG board to a servo hand, with their own safety layer
Not for.
  • Clinical or medical use: not clinical advice and not a medical device
  • Attaching to a person without independent current limits, end-stops and a watchdog in firmware
  • Claiming real-world accuracy: the demo data is synthetic and optimistic

Install

  1. Clone the repository
    git clone https://github.com/herrrickshaw/bionic-limb-control.git
cd bionic-limb-control
  2. Create an environment and install
    python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Quick start: commands and what you should see

Run the synthetic demo

.venv/bin/python emg_decoder.py --demo

A classification report, confusion matrix, per-channel mean frequency, an online replay and a direct-control demo print to the terminal.

Use your own recording

.venv/bin/python emg_decoder.py --csv rec.csv --fs 2000 --mains 50

Same report on your CSV (one column per channel plus optional label and rep columns). I did not run this path.

Limits and honest caveats

  • Not clinical advice and not a medical device. Never attach to a person without firmware-level current limits, end-stops and a watchdog.
  • Demo data is synthetic, so 97.2% is optimistic; the README expects 75-90% on real amputee data and lower across sessions.
  • My online agreement was 88.2%, the README quotes 89%; the small difference is run-to-run variation, not investigated further.
  • Synthetic mean frequency printed about 167-186 Hz, while the README says real muscle is about 60-120 Hz, so that check only makes sense on real recordings.
  • I did not run the --csv path.
