Why it is useful

  • Agricultural economists, commodity analysts and journalists get Agmarknet and UPAG as ready CSVs: no portal clicking, no login, no reverse-engineering of UPAG's Dash callbacks (the collectors already do that and are documented in docs/).
  • It replaces the hour-long portal pull and the messy join: crosswalks map Agmarknet commodity and state names to UPAG's, including the paddy x 0.67 to milled-rice conversion, and build_insights.py produces arrivals-as-share-of-production, mandi-vs-MSP, volatility and top-mandi tables in one run.
  • The joined view answers what neither portal does alone: how much of a state's crop reaches regulated markets, how often mandi prices sit below MSP, and which mandis dominate each crop.
  • Evidence from the run: pip install plus python analysis/build_insights.py regenerated all 14 report files in 16 seconds and git status stayed clean, so the committed tables are reproducible. Example finding: Madhya Pradesh wheat moved from 6.4% below MSP in May 2026 to 2.9% above in October 2026.

What it is for

The repo is a point-in-time open-data extract plus the code to rebuild it. data/agmarknet/ holds state-monthly prices and arrivals, a market-level daily sample (23 field crops, every sixth day since Nov 2025) and the master lists; data/upag/ holds APY by state and district, MSP, WPI, FCI procurement, DGCIS trade and the crop calendar. analysis/ turns them into reports/ (CSV and INSIGHTS.md), and collectors/ refresh the data from the two portals using only the Python standard library, with a cache so interrupted runs resume.

Use it to read the committed tables straight away, to rebuild them after editing the analysis, or to refresh the data yourself. Data is Government of India open data re-published under GODL-India; code is MIT.

Who it is for

  • Agri-economists and policy analysts comparing mandi prices with MSP or market arrivals with production
  • Commodity and food-sector analysts who need a quick, citable view of seasonality and volatility by crop and state
  • Data journalists and students who want clean government agri data without building a scraper
Not for.
  • Trading or hedging decisions. Prices mix varieties and grades and arrivals are what markets choose to report. This is not investment advice
  • Official statistics: the files are an unofficial extract; check figures against agmarknet.gov.in and upag.gov.in before relying on them
  • Lot-level trades, district cumulative arrivals or anything behind a login or captcha: these are out of scope

Install

  1. Clone the repository
    git clone https://github.com/herrrickshaw/india-mandi-arrivals.git
cd india-mandi-arrivals
  2. Create a virtual environment and install the analysis dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

Quick start: commands and what you should see

Check the main files load and how big they are

python3 -c "import pandas as pd
for f in ['data/agmarknet/state_monthly.csv.gz','data/agmarknet/market_daily_sample.csv.gz','data/upag/apy_state.csv.gz','data/upag/msp.csv.gz']:
    d=pd.read_csv(f); print(f, len(d), list(d.columns)[:6])"

state_monthly 203,798 rows (month, commodity_id, commodity, group, state, arrivals_t, price_rs_qtl); market_daily_sample 275,423 rows; apy_state 173,967 rows; msp 1,003 rows.

Rebuild the 14 insight tables from the data

python analysis/build_insights.py

wrote reports/: ['INSIGHTS.md', 'area_by_crop.csv', 'arrivals_share_of_production.csv', ... 'yield_trends.csv'] after about 16 s; git status shows no changes because the committed tables are reproduced exactly.

Read the headline tables

grep '^## ' reports/INSIGHTS.md

Six sections: arrivals as a share of production (2025-26), mandi prices against MSP (last 24 months), most and least volatile large markets, yield growth, area by crop, largest mandis.

Limits and honest caveats

  • The collectors were not run in this post (they call the two portals, Agmarknet throttles to roughly one request per 1.5 s, and a full refresh takes about an hour). Everything shown is from the committed extract, latest month October 2026.
  • Arrivals are what markets report. Markets reporting irregularly are understated, grain bought directly by government agencies or traded outside APMCs is missing, and Agmarknet widened its market coverage from November 2025, so recent arrivals are not comparable with earlier years.
  • Shares above 100% of production and near-zero volatility series are reporting patterns (inter-state flows, support-price recording), not errors; prices mix varieties and grades; UPAG's latest year is an advance estimate.
  • The market-level sample is every sixth day; annual mandi figures are sampled tonnes x 6. UPAG's data callbacks are an internal UI contract and can change on a redeploy.
  • Data is re-published under GODL-India: attribute Agmarknet and UPAG, do not imply endorsement, and check figures against the source portals. Not investment advice.
