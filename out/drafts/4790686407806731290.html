Why it is useful

  • Anyone extracting figures from financial documents with an LLM gets a cheap guard against invented numbers: each field must come with a verbatim quote, and the quote is checked against the document text.
  • It replaces blind trust in the model's JSON. The array-field fix matters because a list of holdings correctly comes back with one quote per item, and the old check marked such a perfectly good extraction as ungrounded.
  • Evidence from the run: the same inputs gave grounded=False before the fix and grounded=True after for a list of two verbatim spans, while a list with one invented span, an empty list and null all still failed.
  • Honest scope: it proves the quote exists, not that a computed value (such as a midpoint) is right. The docstring says so and recommends recomputing derived values yourself.

What it is for

llm_extract.py exposes extract_structured(text, schema): it prompts a Groq model (Gemini as fallback) for fields plus citations, verifies each citation against the text and adds a _grounding map saying which fields are grounded.

This post shows the verification step on its own, which runs offline with no keys. The live LLM call needs your own Groq or Gemini key and was not run for this post.

Who it is for

  • Developers parsing filings or statements with an LLM
  • People who want a small, readable example of citation grounding
  • Teams adding regression tests to an extraction prompt
Not for.
  • Treating grounded=True as proof a number is correct: it only proves the quote is real
  • Legal or investment decisions: this is not legal advice and not investment advice
  • A drop-in library: it is a single file copied out of a larger project, with no packaging or tests of its own

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/llm-extract-citation-fix.git
cd llm-extract-citation-fix
  2. Optional, only for live LLM calls
    python3 -m venv .venv && source .venv/bin/activate
pip install openai
export GROQ_API_KEY=your-own-key

Quick start: commands and what you should see

Check a citation against source text, no key needed

python3 -c "from llm_extract import _verify_citation as v; src='TCS  Qty 5   Avg 3200.50'; print(v(['TCS  Qty 5   Avg 3200.50'], src), v(['WIPRO Qty 7'], src))"

True False: a list of per-item quotes passes only if every quote is in the text.

Run the built-in demo (needs a key)

python3 llm_extract.py --demo portfolio

A JSON object with holdings, cash_balance and a _grounding map. Not run for this post.

Limits and honest caveats

  • Not legal advice and not investment advice.
  • The live extraction path was not run: it needs your own API key. Only the offline verifier was exercised.
  • Grounding proves a quote exists, not that a derived value is correct (the file's own docstring says so).
  • The default model names in the file (llama-3.3-70b-versatile, gemini-2.0-flash) are retired by their providers per the sibling repo's notes; set GROQ_MODEL and GEMINI_MODEL yourself.
  • The file contains no tests, requirements file or packaging.
