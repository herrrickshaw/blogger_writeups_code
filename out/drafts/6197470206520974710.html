Why it is useful

  • Self-directed researchers and students who want to see Darvas, Piotroski, Coffee Can, GARP and other classic screens implemented in one readable code base get a working, auditable example.
  • It replaces collecting prices market by market: the repo bundles cached prices for 17 markets, so a first screen runs in minutes with no API key and no LLM tokens.
  • Evidence from the run: first-time bootstrap built a 22,548-symbol local LMDB store (about 250 MB) and a Darvas screen on Korea returned six breakout names in seconds.
  • It is honest about its limits: the public copy leaves out screener.in data, and my run found that the cache ends on 2 July 2026 and that the US market is not in the bundled seeds.

What it is for

Global Stock Screener turns a bundle of cached end-of-day prices into ranked screen results. You pick a strategy (piotroski, coffee_can, magic_formula, garp, darvas and others) and a market code, and it prints a table with price, distance from the 52-week high, volume ratio and a liquidity tier, then saves a CSV in results/.

This post covers the public copy of the repository. The author removed screener.in exports from it because they cannot be redistributed, so India screens that depend on them need your own data.

Who it is for

  • Students learning how momentum and quality screens are built
  • Researchers who want a reproducible, key-free price cache to test ideas on
  • Developers looking for a worked example of an LMDB-backed market data store
Not for.
  • Investment advice: this is not investment advice, and nothing here is a recommendation to buy or sell
  • Live signals: the shipped cache ends on 2 July 2026, so results describe that date, not today
  • Fundamental screens for India or the US without supplying your own data

Install

  1. Clone the repository (the data files are ordinary git objects in this public copy)
    git clone https://github.com/herrrickshaw/global-stock-screener-public.git
cd global-stock-screener-public
  2. Create an environment and install dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

Quick start: commands and what you should see

List strategies and markets

python run.py --list

Prints the 11 strategies (piotroski, coffee_can, magic_formula, bluest_blue_chips, debt_reduction, dividend_yield, golden_crossover, loss_to_profit, garp, darvas, cash_conversion_cycle) and 20 market codes.

Run a Darvas breakout screen on Korea

python run.py --strategy darvas --market KR --top 6

On the first run it builds the local store (about 90 seconds here), then prints a table of breakout names and saves results/darvas_KR.csv.

Limits and honest caveats

  • Not investment advice. Screen output is a mechanical filter, not a buy or sell signal.
  • Data date: the shipped cache's latest bar is 2 July 2026, four months before this run. Treat results as a demonstration of the method.
  • Bug found: the default python run.py leaderboard crashes with IndexError: At least one sheet must be visible when no stock passes the momentum and golden-cross filters; the per-market counts print first. Single-strategy runs such as --strategy darvas --market KR worked.
  • The US market is not part of the bundled seeds, so US screens return nothing without your own price data.
  • Test suite: 152 passed and 1 failed (tests/test_query.py::test_ltm_view_and_market_col expects a US view that the public copy does not have).
  • The public copy removes screener.in data (26 public screens, the India CCC screen and the India fundamentals cache); India fundamental screens need your own access to that source.
  • Check the licence and terms of any data source before you reuse its data.
