Why it is useful

  • Who benefits: anyone who needs a list of tradable symbols per country before downloading prices or fundamentals, such as students, analysts and hobby quants.
  • What it replaces: scraping each exchange website or hand-typing watch lists. One call, tickers_for('JP'), returns the Japan list.
  • Symbols carry the exchange: India comes as RELIANCE.NS or .BO, Japan as 7203.T, Germany as SAP.DE. In the run, 7203.T was found in JP only, 005930.KS in KR only and SAP.DE in DE only, so the suffix tells you the venue.
  • Evidence from the run: the helper loaded 74,239 symbols across 34 markets in well under a second, all unique, and the 16 bundled tests passed.

What it is for

The repository stores one JSON file, data/global_universe.json, with a list of Yahoo-Finance-style symbols per market, plus a helper module, global_tickers.py. You import the helper and ask for a market, several markets, or everything.

It is a universe list, not a price or fundamentals source. Use it as the input to a screener or data collector. Not investment advice: this is research and education material built from public-source or derived data; it is not a recommendation to buy or sell anything.

Who it is for

  • Students and analysts building multi-country screens
  • Data engineers who need a seed list for a price or fundamentals collector
  • Non-programmers who want an AI assistant to filter the CSV for them
Not for.
  • Live prices, fundamentals or trading signals. The repo holds symbols and names only.
  • Treating the list as complete or current. It is a snapshot, and some markets are only partly covered (see limits).
  • Investment decisions. Not investment advice: this is research and education material built from public-source or derived data; it is not a recommendation to buy or sell anything.

Quick start: commands and what you should see

Print the market summary table

python3 global_tickers.py

A table of market code, exchange and ticker count, then the first five tickers for India, the US and Japan.

Pull symbols in your own script

from global_tickers import tickers_for, market_codes
print(market_codes()[:5])
print(tickers_for('JP')[:3])

['IN', 'US', 'JP', 'KR', 'AU'] and ['1301.T', '1332.T', '1333.T'].

Run the tests

python3 -m pytest -q

16 passed.

Limits and honest caveats

  • Snapshot only. The README says the validated flat file is as of July 2026; nothing refreshes it automatically.
  • Mismatch found in the run: the README says the universe was widened to 75,815 symbols, with Taiwan 1,958 and Singapore 854 after the TPEX and SGX merge. The committed global_universe.json loaded in this run gives 74,239 symbols, Taiwan 1,065 and Singapore 171, and the README itself says the 60,971 flat file is separate from the later additions. Treat counts in the README and in the JSON as different snapshots.
  • US symbols are bare (for example 'A', 'AA'); the exchange (NYSE, NASDAQ, AMEX) is not in the symbol. Do not infer an exchange from the ticker shape.
  • Some markets are small samples (Poland 20, Belgium 20, Greece 25), and China is flagged in the README as a coverage gap.
  • The SGX list has no published reuse licence; check the exchange terms before redistributing. The TPEX list needs attribution.
  • Symbols are not validated for being tradable today. Not investment advice: this is research and education material built from public-source or derived data; it is not a recommendation to buy or sell anything.
