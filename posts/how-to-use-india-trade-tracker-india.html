Why it is useful

  • Exporters, policy students and analysts who want India's trade by product group without a paid vendor get a chapter-by-chapter table straight from the government's own data bank.
  • It replaces repeated manual downloads from a JavaScript-heavy website: a Selenium collector handles the form and stores each pull in DuckDB with the pull date.
  • The committed CSV snapshot already holds two financial years for both flows, so the demo ran with no browser and no network: 17 tests passed and the queries below took seconds.
  • Evidence from the run: summing the chapters reproduced the official FY2024-25 totals the README cites (about US$ 438 bn exports, about US$ 721 bn imports).

What it is for

india-trade-tracker collects India's annual merchandise exports and imports by 2-digit HS chapter (US$ million, current and previous year, growth percent) from the DGFT / Department of Commerce Export-Import Data Bank, using headless Chrome because the site is JS-rendered.

It also pulls a World Bank trade indicator panel, bilateral monthly data and HS8 detail from the NIRYAT portal, and India chapter totals from the UN Comtrade public preview API.

Who it is for

  • Students and researchers studying India's trade structure
  • Exporters and consultants scanning which chapters are growing or shrinking
  • Developers building trade dashboards
Not for.
  • Legal or customs-classification advice: this is not legal advice and not an official customs reference
  • Shipment-level or company-level data (it is chapter totals, not bills of lading)
  • Investment decisions: not investment advice

Install

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/india-trade-tracker.git
cd india-trade-tracker
  2. Create a virtual environment and install dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt pytest

Quick start: commands and what you should see

Run the test suite (no browser or network needed)

python -m pytest -q

17 passed in about 1.5 seconds.

Pull a financial year live from EIDB (needs Chrome and network; not run in this demo)

python3 collectors/eidb_trade.py --year 2024

Chapter rows for exports and imports are written to data/trade.duckdb.

Query the committed snapshot with DuckDB

python3 -c "import duckdb; print(duckdb.sql(\"select flow, fy_start, count(*) chapters, round(sum(cur_year_usd_mn)) usd_mn from read_csv_auto('data/eidb_chapter_trade_snapshot.csv') group by all order by 1,2\"))"

Four rows (exports and imports for two financial years), 97 chapters each.

Limits and honest caveats

  • Not legal advice and not an official statistic; figures are as published by the Department of Commerce data bank and may be revised.
  • I did not run the live EIDB collector (needs Chrome and network). Outputs shown come from the committed snapshot and the test suite, run 19 Oct 2026.
  • The snapshot holds only two financial years (FY2024-25 and FY2025-26) at 2-digit chapter level; the FY2025-26 pull was made on 15 Sep 2026, so check how complete that year is before relying on it.
  • Chapter totals are annual; monthly series and 4/6/8-digit drill-down are on the README roadmap. NIRYAT HS8 data exists but is limited to a few partner countries.
  • The NIRYAT collector disables TLS verification because of a certificate mismatch on that site, per the README; understand that trade-off before using it.
  • The 'sum of chapters' totals are my aggregation of the committed rows.
