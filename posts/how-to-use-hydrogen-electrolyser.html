Why it is useful

  • Who benefits: students and engineers who want a runnable sketch of how an electrolyser controller is structured (setpoints, ramps, safety limits, logging, an API) before touching hardware.
  • What it replaces: writing the plumbing yourself. One command compares three electrolyser types and another exposes control over HTTP.
  • Evidence from the run: 7 of 8 bundled examples completed; the PEM, AEM and alkaline comparison printed efficiencies of 75.0, 72.0 and 68.0 percent.
  • It also shows the limits honestly: I found a crash, a voltage setpoint that is silently clamped, and a production table that is physically wrong. Those are listed below so you do not trust the wrong numbers.

What it is for

The repository holds a control system for three electrolyser types, an advanced layer with ramp profiles, data logging and safety interlocks, a Flask REST API with a Python client, and eight runnable examples. Everything runs against a software model, not a device.

Its own validation notes say that every test used synthetic power profiles and that no hardware testing was done. Simulation only, not for operating real electrolysers. The repository is archived, so it will not receive fixes; treat it as a teaching reference.

Who it is for

  • Students learning how electrolyser control is organised
  • Energy analysts who want a toy model to explain ramping and safety limits
  • Non-programmers who want an AI assistant to walk through each module
Not for.
  • Operating, commanding or commissioning a real electrolyser. This is simulation only.
  • Sizing, costing or certifying hydrogen plant. It is not an engineering design.
  • Quoting its hydrogen production numbers. The production table I ran is physically wrong (see limits).

Install

  1. Get the code (the repository is archived, so you can clone it but not push)
    git clone https://github.com/herrrickshaw/hydrogen-electrolyser-control.git
cd hydrogen-electrolyser-control
  2. Create an environment and install
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

Quick start: commands and what you should see

Run one example. The menu is interactive, so pipe the choice in

echo 5 | python electrolyser_examples.py

Three runs (PEM, AEM, alkaline) and a comparison summary.

Run the ramp profile example

echo 4 | python electrolyser_examples.py

A time series of voltage, power and efficiency as a ramp is applied.

Start the REST API and drive it with curl

python electrolyser_web_api.py PEM 5000
curl -X POST localhost:5000/api/control/start
curl -X POST localhost:5000/api/control/voltage -H 'Content-Type: application/json' -d '{"voltage": 45.0}'
curl localhost:5000/api/status

JSON replies. Note the README mentions a /api/production path, but the code serves /api/monitoring/production.

Run example 7 (safety limits) to see the crash

echo 7 | python electrolyser_examples.py

The limits print, then an AttributeError traceback.

Limits and honest caveats

  • Simulation only, not for operating real electrolysers. The repository's own validation notes say all testing used synthetic power profiles and that no hardware testing was done.
  • The repository is archived: no fixes will be merged.
  • Example 7 crashes with AttributeError (the control system has no safety_monitor attribute). Examples 1 to 6 and 8 completed.
  • Setting 45 V does not take effect in the runs I did: example 1 reports 30.0 V throughout, and the log shows 'Voltage 30.0V out of range' errors at start-up.
  • Example 8 prints 316 Nm³/h of hydrogen at every power level with 0 V and 0 A, which contradicts the 0.95 Nm³/h spec in the same code.
  • Example 2 prints many 'Voltage too low' warnings during the ramp from near zero.
  • The README says 'Status: Production Ready' and quotes performance figures; I did not verify those and the validation notes contradict the readiness claim.
  • The examples write log and CSV files into the current folder.
