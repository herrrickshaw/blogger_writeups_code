What it is for

global-stock-screener ships about a year of cached price data and some cached company fundamentals. You clone it and run classic rule-based screens in minutes: Darvas breakouts (price near a 52-week high on heavy volume), the Piotroski F-Score (nine yes/no financial health tests) and Coffee Can (high return on equity, steady growth, low debt).

A second repo, global-market-scanners, runs full-market scans for Europe, Japan and Korea and writes Excel files. Its scanning logic is unit tested offline; the full scans themselves fetch live data and were not run in the demo.

A small decision engine blends valuation, momentum, quality and recovery into a BUY, HOLD or SELL label, with an IMPAIRED override for broken companies. All output is a mechanical filter for research. It is not investment advice.

Who it is for

  • Students and self-taught investors who want to see how classic screens work
  • Engineers who want a plug-in framework for their own screening rules
  • Researchers who need a reproducible, keyless baseline
Not for.
  • Making buy or sell decisions. The screens are filters, not advice
  • Live trading or current prices: the cache ends in late June 2026
  • Complete coverage of India, US, Japan, Korea or China prices: those price panels are not in the cache

Install

  1. Clone with Git LFS so the price data downloads
    git lfs install
git clone https://github.com/herrrickshaw/global-stock-screener.git
cd global-stock-screener
git lfs pull
  2. Create a virtual environment and install the requirements
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
  3. Optional: check readiness (LFS data pulled, packages present)
    python preflight.py
  4. Optional, for the full-market scans: clone the second repo
    git clone https://github.com/herrrickshaw/global-market-scanners.git
cd global-market-scanners && pip install -r requirements.txt

Quick start: commands and what you should see

Run a Darvas breakout scan on cached German stocks

python run.py --strategy darvas --market DE --top 8

With data as of 29 June 2026, one name passed: NA9.DE, 4.11% below its 52-week high, volume 15.58 times its 20-day average, flagged BREAKOUT. The same scan on UK printed 'No hits for darvas on UK.', because the rule is strict (within 10% of the 52-week high and volume at least 1.5 times average).

Run the Piotroski and Coffee Can strategy modules on the cached fundamentals (called from Python, as in the demo)

strategies.piotroski.screen()   # over cache_seed/fundamentals/US and IN
strategies.coffee_can.screen()  # same data

These are Python calls, not run.py flags. Each strategy module declares META and a screen() function. In the demo, Piotroski evaluated 346 US names and 75 scored 7 or more (NTAP, LHX and CSCO scored 9). In India it evaluated 16 names and 1 passed (ICICIBANK, 7). Coffee Can evaluated 338 US names and 11 passed (for example NVDA, ANET, META).

Run the offline tests

pytest tests/test_strategies.py

8 passed in the demo. The wider suite (excluding the unit and integration folders) gave 130 passed and 1 skipped. In global-market-scanners, pytest tests/ gave 121 passed in 20.49 seconds.

  • Explain decision_engine.py: the four factor weights, and what the IMPAIRED flag does.

Limits and honest caveats

  • Educational and research use only. Not investment advice. Screens are mechanical filters.
  • The price cache ends between 26 and 30 June 2026. India, US, Japan, Korea and China price panels are not in the cache, so those markets return no price-based hits.
  • Fundamentals are cached only for India (18 names) and the US (376 names), with no as-of date in the files.
  • Coffee Can: negative revenue crashes the cagr() calculation (3 US rows crashed). For India, revenue five years ago exceeds current revenue for every name, so every growth figure is negative and nothing passes. The cached field looks wrong.
  • Piotroski for India caps at 8 because the cache has no gross margin field.
  • Darvas box levels in the scanners repo are rounded to whole numbers, which is coarse for low-priced euro stocks.
  • The tests/unit and tests/integration folders in global-stock-screener fail to collect (ModuleNotFoundError: No module named 'src'), so they were not run.
  • The decision-engine example in the demo used the repo's own test fixtures, not live picks.
  • The full-market scans in global-market-scanners fetch live data and were not run in the demo.
