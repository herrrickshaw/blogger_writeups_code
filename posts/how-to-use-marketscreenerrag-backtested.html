What it is for

Most stock factors do not work everywhere. This tool keeps a short knowledge base of what the authors' backtests found for each market, including the results that failed. It reports each strategy's historical earnings with its significance tests (t-stat and Deflated Sharpe), and it states clearly when a market has no edge.

You can ask it for a market's strategy, run that market's screen on a bundled snapshot of company ratios to see example picks, list the historical earnings of every strategy, or ask a free-form question. Answers come from the stored backtest results. The tool does not invent numbers.

It is for learning and research. It is not a trading system.

Who it is for

  • Students and analysts who want to see how backtested evidence differs by market
  • Engineers who want a small example of a rule-based knowledge base with TF-IDF search (no model, no API)
  • Anyone who wants a plain-language look at why nulls and failed strategies matter
Not for.
  • Investment advice. The README and every output say research and education only
  • Live trading. All earnings are gross of costs and short-borrow, on survivorship-biased universes
  • Using the picks as they are. The snapshot is bundled data, not a live feed, so validate each name yourself

Install

  1. Clone the repo and create a virtual environment.
    git clone https://github.com/herrrickshaw/market_screener_rag.git
cd market_screener_rag
python3 -m venv .venv
source .venv/bin/activate
  2. Install the three dependencies.
    pip install -r requirements.txt

Quick start: commands and what you should see

See the winning strategy for one market (Korea).

python screener_rag.py strategy KR

A page headed Korea, winning strategy (backtested). Character: mean-reversion. Book: full long/short. It lists the long and short rules and the earnings, including +4.83% per 6 months at t 4.17, and ends with the verdict TRUST and a research-only note.

Compare the historical earnings of every market's strategy.

python screener_rag.py earnings

A table with one row per market (India, US, Korea, Europe, Japan, China), each with its strategy, earnings and significance. Japan shows +6.6% per 6 months (t 4.84). China shows value failing, with a spread near 0% (t 0.04), which the tool labels a real null result.

Apply the India screen to the bundled snapshot.

python screener_rag.py screen IN

A long list of 15 cheap-for-quality names with PE, PB, ROE and a valuation score, all marked UNDERPRICED. It ends with: no short book, because shorting fails in India (-1.0% per 6 months), and a note that the list is gross of costs and not investment advice.

Ask a free-form question.

python screener_rag.py ask "does value work in china"

The line (best match: China), then the China page. The verdict is that value-reversion fails in China (a powered null) and that a value screen should not be run there.

See the one finding that holds across markets.

python screener_rag.py universal

A short note that momentum/trend in bull regimes is the one metric that works in nearly every market and survives the multiple-testing check. Mean-reversion is fragile everywhere.

Sample prompts for your AI assistant

Copy, paste and edit the parts in [brackets].

  • Read README.md and GLOSSARY.md and explain in plain English what a t-stat and a Deflated Sharpe ratio tell me about a strategy.
  • Run python screener_rag.py earnings and summarise which markets have a tested edge, which have a null result, and which do not have enough data.
  • Explain why the tool says there is no short book in India, and show me where that comes from in winning_strategies.json.
  • I want to see how screen rules are applied. Walk me through the screen code in screener_rag.py for Korea, step by step, without changing anything.
  • How would I add my own market or strategy to winning_strategies.json? List the fields I would need and the data I would have to bring.
  • List every reason I should not trade on these picks, using the limits written in the README.

Limits and honest caveats

  • Research and education only. Not investment advice.
  • All earnings are gross of costs and short-borrow, on survivorship-biased universes. Read the spreads, not the levels.
  • Capacity is small: roughly 300 to 500 thousand dollars before the illiquidity edge decays. The tool says the real edge is illiquidity, not size.
  • Annualised figures are indicative, not compounded guarantees.
  • The Japan panel is a sample of about 1,437 firms, and China coverage is thin (426 of about 3,454 liquid stocks).
  • The screen runs on a bundled snapshot of ratios, not live data. Validate each name before acting on it.
  • The repo has no test suite or evaluation harness. The demo ran the command-line tool only, so the backtests were not re-run or independently checked.
  • The demo showed only the first lines of the India screen. The output shown in the video is trimmed.
