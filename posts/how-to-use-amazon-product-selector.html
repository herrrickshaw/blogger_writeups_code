Why it is useful

  • Sellers who pick products by looking at the biggest category end up fighting incumbents; this tool asks two questions first, is demand rising and can a newcomer get in.
  • Pass/fail gates run before ranking and every rejection records its reason, so you learn why a keyword failed (flat trend, price below the B2B floor) instead of just seeing a lower score.
  • B2C and B2B run as separate analyses with their own search terms and thresholds, and the comparison shows terms that are open on only one side.
  • Evidence from the run: 162 tests passed, and the offline dry run shortlisted 3 of 4 keywords for B2C and 2 of 4 for B2B with reasons for each rejection.

What it is for

The tool takes a list of candidate keywords, reads a weekly search-volume trend and a snapshot of competing listings, and writes a ranked shortlist plus a rejected list with reasons. India (amazon.in, INR) is the default marketplace.

The offline --dry-run mode uses built-in fixture data and makes no network call, so you can see the whole pipeline and report format before paying for any data API. This post ran only that mode; live runs need two third-party API keys and were not run.

Who it is for

  • Small sellers and category analysts screening a long keyword list before spending on inventory
  • Anyone who wants a transparent gate-then-rank method they can edit (thresholds live in one MARKETS table)
Not for.
  • Guaranteeing a product will sell: the volume scales for India are estimates and nothing is calibrated against observed data
  • Reading an individual shopper's search history (no such API exists)
  • Anyone expecting the dry-run numbers to describe the real market: they are fixtures

Quick start: commands and what you should see

Offline demo, no keys, no network

python3 amazon_selector/shortlist.py --dry-run

Prints a B2C section, a B2B section and a B2C-vs-B2B comparison, then lists the report files it wrote under reports/.

Run the tests

python3 -m pytest -q

162 passed, 2 skipped on the demo run.

Live run on the India universe (needs keys)

export NEXSCOPE_API_KEY=...  NEXSCOPE_PROXY_BASE=https://api.nexscope.ai/
export OPENWEB_NINJA_API_KEY=...
python3 amazon_selector/shortlist.py --keywords-file candidates_in.txt --profile both

Not run for this post. Cached responses expire (24h competition, 168h trend).

Limits and honest caveats

  • Volume scales for India are estimates and uncalibrated, per the README.
  • Observed quirk in the dry run: chyawanprash is B2B-shortlisted with every component score at 0.000, so shortlisted does not mean strong.
  • Live mode depends on two third-party APIs whose terms and prices change; not run here.
  • Dry-run data is fixture data and must not be read as a market finding.
  • This is a research aid, not business or investment advice.
