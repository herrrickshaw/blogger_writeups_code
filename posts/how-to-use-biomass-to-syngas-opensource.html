What it is for

India has an estimated 230 million tonnes a year of unutilised agricultural biomass, and open-field burning is a seasonal air-quality problem. Gasification is one proposed alternative, but it needs a sizing estimate first.

This toolkit gives a traceable first estimate: feedstock characterisation, a gasifier at a chosen temperature and type, tar and particulate cleanup, and a screening of syngas quality for its likely use.

Who it is for

  • Students and analysts exploring biomass-to-energy options
  • Early-stage project teams who need a quick comparison of gasifier types
  • Anyone who wants an estimate they can trace to a literature source
Not for.
  • Detailed engineering design
  • Rate-based cleanup sizing or collection and logistics planning

Install

  1. Make sure Python 3.10 or newer is installed
    python3 --version
  2. Create and activate a virtual environment (keeps the install tidy)
    python3 -m venv .venv && source .venv/bin/activate
  3. Install the package with the test tools. The dependencies (CoolProp, pandas, plotly, streamlit or scipy/numpy) come in automatically from pyproject.toml.
    pip install -e ".[dev]"

Quick start: commands and what you should see

Run the tests

pytest -q tests

18 passed in about 1.3 seconds in the demo.

Size a gasifier for 100 t/day of rice straw

python examples/full_chain_worked_example.py

87.43 mol/s of syngas at 850 C in a fluidized bed, 75.8% cold gas efficiency, tar cut from 29.40 g/s to 0.882 g/s after cleanup, H2:CO of 1.73:1, LHV 5.71 MJ/Nm3 and 50.2% inert gas. The recommended use is direct combustion or gas-engine power only, because the inert share is too high for chemical synthesis.

Optional: interactive app

streamlit run streamlit_app.py

A local web page opens. Present in the repo; not part of the captured demo.

Limits and honest caveats

  • Conceptual sizing, not detailed engineering design.
  • Measured in the demo: tar yield stayed at 29.39 g/s from 750 to 950 C. It is a lookup by gasifier type, not a temperature model.
  • Measured: cold gas efficiency was 75.8% at every temperature in the sweep, so do not use the model to find an optimum temperature.
  • The syngas was 50.2% inert, so it is rated for power, not as a chemical synthesis feed.
  • The README notes fixed conversions and no rate-based cleanup sizing. Collection and logistics of the straw are the real barrier.
  • The repo as checked has no LICENSE file; check the repo page before reusing the code.
