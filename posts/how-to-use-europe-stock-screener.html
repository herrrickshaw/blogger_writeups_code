Why it is useful

  • Retail researchers and students get a no-account way to rank European stocks on trend and quality signals across exchanges that most free screeners ignore, including the Baltics, Prague, Budapest and Bucharest.
  • It replaces hand-built spreadsheet screens with a repeatable command that writes sorted CSVs for two scoring schemes.
  • Evidence from the run: a 40-ticker Frankfurt smoke scan finished with exit 0 and produced both reports, but only 19 of 40 tickers returned data, so check coverage before trusting any ranking.
  • Everything comes from public Yahoo Finance data through yfinance: no database, broker or paid vendor feed.

What it is for

run_scan.py downloads price history in batches, computes RSI, EMAs, MACD, Bollinger, stochastic, ATR and returns, then scores each stock two ways: Darvas/Buffett (momentum with an optional fundamentals overlay) and a simplified Piotroski (momentum proxies plus fundamentals when fetched).

Scores are mechanical screens for research and education. A high score is a prompt to investigate, not a recommendation.

Who it is for

  • Students and self-directed investors exploring European markets
  • Analysts who want a worked example of vectorised pandas scoring
  • Anyone building a first-pass European watchlist generator
Not for.
  • Investment advice: this is not investment advice
  • A backtest: it is a live snapshot with no survivorship-bias handling
  • Complete coverage: Yahoo data gaps and rate limits drop tickers silently

Install

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/europe-stock-screener.git
cd europe-stock-screener
  2. Create a virtual environment and install
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

Quick start: commands and what you should see

Smoke test on one exchange

python run_scan.py --exchange "Deutsche Boerse Frankfurt" --limit 40 --out reports

A line with the universe size, a fetched-count line, BUY/WATCH/AVOID counts and the top scores for both scans, then two CSVs in reports/.

Full fast pass (OHLCV and RSI only)

python run_scan.py

Same outputs for the whole universe; the README estimates 5-10 minutes, but expect longer if Yahoo throttles.

Limits and honest caveats

  • Not investment advice. Mechanical screens fail in regime changes.
  • Coverage was poor in the demo: 19 of 40 Frankfurt tickers returned data, and the 40-ticker run took 426 seconds, so the 5-10 minute full-universe estimate looks optimistic on this day and network.
  • The README is inconsistent about size: its text says 1,063 stocks on 23 exchanges, but the usage notes and docstring still say 966 stocks and 17 exchanges; the CSV has 1,063 data rows.
  • No survivorship-bias handling: it is a live snapshot, not a backtest.
  • Data is Yahoo Finance via yfinance, which rate-limits and can change without notice.
