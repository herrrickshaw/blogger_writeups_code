Why it is useful

  • Car buyers, fleet managers and students can compare running costs across fuels with editable inputs instead of trusting a headline claim: choose a city, change the E20 mileage drop or usage, and the whole workbook reprices.
  • It replaces hand-built comparison spreadsheets with an auditable one: formula-driven, with 21 automated checks, and mileage assumptions calibrated on 303 real declarations rather than guesses.
  • Evidence from the run: 19 tests passed, the workbook built in 0.1 s, LibreOffice recalculation reported 0 errors, and the Checks sheet read ALL PASS.
  • The same data showed the E20 effect on an average petrol car: 16.67 kmpl falls to about 16.0 kmpl at a 4% drop.

What it is for

vehicle_fuel_mileage builds an 11-sheet Excel cost model (cities, cost per km, ethanol impact, total cost of ownership, tax structure, fleet sales, OMC price board, exchequer revenue) on a July 2026 price basis, plus a Word report builder and a script that extracts and analyses fuel-efficiency declarations from the SIAM PDF.

This post covers the model workbook and the declaration analysis. Prices are inputs in the workbook: update them to today's before drawing conclusions.

Who it is for

  • Vehicle buyers comparing petrol, diesel, CNG and EV running cost
  • Students and analysts studying fuel taxation and ethanol blending
  • Developers who want a worked example of a tested, formula-driven Excel build
Not for.
  • Investment advice: this is not investment advice
  • A purchase decision on its own: it covers running cost, not resale, insurance or availability of charging or CNG
  • Current prices: inputs are a July 2026 snapshot

Install

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/vehicle_fuel_mileage.git
cd vehicle_fuel_mileage
  2. Create a virtual environment and install dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt

Quick start: commands and what you should see

Run the tests

python -m pytest -q

19 passed in about 1.5 seconds.

Analyse the 303 fuel-efficiency declarations

python scripts/analyze_fe_declarations.py

A fuel-type summary table, the petrol-to-CNG uplift, and the E20 mileage haircut.

Build the Excel model, then recalculate it

python scripts/build_model.py
python scripts/recalc.py outputs/EV_CNG_Diesel_Ethanol_Vehicle_Cost_Model.xlsx

A saved workbook with 11 sheets, then JSON reporting status success and 0 errors. Open the CostPerKm sheet.

Limits and honest caveats

  • Not investment advice. Running cost only.
  • Fuel and electricity prices are a July 2026 snapshot (Delhi petrol Rs 102.12/L in the model); update them before using results.
  • The built workbook has no cached values until recalculated; I recalculated with LibreOffice (soffice) to read the numbers shown. Open in Excel or run scripts/recalc.py.
  • The SIAM declaration dataset is from passenger vehicles as on 1 April 2020; it has only 11 CNG, 8 hybrid and 1 electric entries, so those means are thin.
  • Two-wheeler CNG (102 km/kg) in the CostPerKm sheet is a modelling assumption for comparison, not a product widely sold; treat it with caution.
  • State VAT rates are indicative effective rates; several states add per-litre cesses.
  • I did not run the Word report builder (Node).
