Why it is useful

  • Industrial-policy analysts and investors scanning for import-substitution gaps get a pre-sorted list of 827 chemical HS-8 lines instead of eight raw TRADESTAT chapter downloads.
  • It replaces a manual rule of thumb with explicit signals: A scissors (value and volume falling, price rising), B inelastic target, D deepening, E no clear signal.
  • Evidence from the run: the committed results show plastics (ch. 39), organic chemicals (ch. 29), fertilisers (ch. 31) and inorganic chemicals (ch. 28) carry $59.3 bn of the $67.9 bn deficit, and 59.6% of codes have no clear one-year signal, a useful reminder of how little one year of data can say.
  • The top lines are fertilisers and precious-metal compounds, which the repo's own rationale tags call structurally import-dependent rather than substitutable.

What it is for

The repo has one analysis script (scripts/hsn8_signal_analysis.py) and its output (data/chem_hsn8_signals.json, plus an HTML registry of codes). For each HS-8 code in chapters 28, 29, 31, 32, 33, 34, 38 and 39 with an FY2025-26 import-minus-export gap of at least $0.5 million, it computes value, volume and unit-price growth and assigns a signal and a keyword-based rationale tag.

The script needs the raw TRADESTAT Excel downloads, which are not in the repo, so this post reads the committed result file.

Who it is for

  • Industrial-policy and PLI analysts
  • Chemical-sector researchers and equity analysts looking for gaps
  • Students of import substitution
  • Developers wanting a worked HS-8 classification example
Not for.
  • Investment advice: this is not investment advice
  • Judging true substitutability: the rationale text is keyword rules, not engineering assessment (conceptual, not engineering design)
  • Multi-year trend claims: the signals use a single fiscal-year change

Quick start: commands and what you should see

Summarise the committed results by chapter and signal

python3 - <<'E'
import json
from collections import Counter
d=json.load(open('data/chem_hsn8_signals.json'))
for ch,v in sorted(d['by_chapter'].items()):
    print(ch, d['ch_names'][ch], len(v), round(sum(r['deficit_fy26'] for r in v)/1e3,1), dict(Counter(r['is_signal'][0] for r in v)))
E

One line per chapter: code count, deficit in US$ billion and a count of signal letters.

List the active-substitution (scissors) codes

python3 - <<'E'
import json
d=json.load(open('data/chem_hsn8_signals.json'))
r=[x for v in d['by_chapter'].values() for x in v if x['is_signal']=='A_SCISSORS']
for x in sorted(r,key=lambda x:-x['deficit_fy26'])[:5]: print(x['hs'],x['name'][:40],x['imp_fy25'],x['imp_fy26'],x['qty_growth_pct'],x['price_growth_pct'])
E

Five HS-8 codes with falling value and volume and rising price.

Limits and honest caveats

  • Not investment advice, and conceptual only: the rationale text comes from keyword rules on product names, not plant or engineering analysis.
  • Single-year window (FY2024-25 to FY2025-26) only. The docstring itself says it lacks the 3-5 year trend, an Import Penetration Ratio, component-shift detection, country-of-origin checks and a tariff/PLI cross-reference.
  • I did not run the script: its raw TRADESTAT Excel inputs are not in the repo. Everything shown is read from the committed results file (last commit 3 October 2026).
  • Unit prices are stored rounded to one decimal, so many per-kg prices show as 0.0 in the file; use price_growth_pct instead.
  • Product names are as served by TRADESTAT, typos included; for example one 'urea' line is labelled 'Fertilizer grade, conforming to Standard' and I paraphrased it in the table.
  • There is no README in the repo, so the usage notes here come from the script docstring.
