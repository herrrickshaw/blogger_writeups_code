Why it is useful

  • Self-directed researchers and students who want to see how Darvas breakout, Piotroski, Coffee Can, Magic Formula and momentum screens can be combined into one score get a readable, auditable implementation.
  • It replaces juggling separate screens: one run gives a sector-capped shortlist, a full ranked CSV and a paper-portfolio file with transparent screen hits for each name.
  • Evidence from the run: a fresh scan of the 300 most liquid US stocks was ranked end to end in under three seconds: 256 passed the liquidity gate, 181 were ranked (24 CORE, 31 QUALITY, 50 MOMENTUM, 76 WATCH).
  • It also shows how fragile a rank is: an earlier attempt with fundamentals missing for 162 of the 300 names produced a different top 15 (12 CORE names, not 24). Missing data silently becomes 'screen not passed', so check coverage before reading the list.

What it is for

us-stock-picks (package us_stock_picks) reads the newest us_full_scan_*.xlsx workbook, applies a liquidity gate (price at least $5, turnover at least $2 million a day), scores ten screens with fixed weights, assigns each stock to a sleeve (CORE, QUALITY, MOMENTUM, WATCH), caps names per sector, and writes HTML, CSV and JSON outputs.

The scan workbook comes from a separate pipeline that is not in this repo. For this run I built one with the Darvas, golden-cross, five fundamental screens and machine-learning stages of the author's sibling BazaarTalks scanner, fed with cached prices (to the 21 October 2026 session) for the 300 most liquid US non-ETF stocks and live fundamentals from Yahoo Finance. A small adapter added turnover, a liquidity tier and an above-EMA50 flag, and I named the file with the session date so the as-of label is right.

Not available in my workbook: the Quality score and grade, the 'Actionable' flag, so those two screens never fire. The full 7,500-stock universe was not scanned.

Who it is for

  • Students learning multi-factor screening
  • Researchers who want a transparent, reproducible ranking recipe
  • Developers building a screening report from tabular scan data
Not for.
  • Investment advice: this is not investment advice, and nothing here is a recommendation to buy or sell
  • Live trading signals: the committed outputs are dated 24 July 2026
  • Running as-is without an upstream scan workbook or a long --refresh data pull

Install

  1. Clone the repository
    git clone https://github.com/herrrickshaw/us-stock-picks.git
cd us-stock-picks
  2. Create an environment and install dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

Quick start: commands and what you should see

See all options

python -m us_stock_picks --help

Usage text listing --scan, --top, --max-per-sector, --portfolio-size, --min-price, --min-turnover, --refresh and --open.

Rank a scan workbook

python run_us_picks.py --scan path/to/us_full_scan_YYYYMMDD_HHMM.xlsx --top 15 --max-per-sector 3 --out outputs

Prints a summary (as of, universe, liquid, ranked, sleeves) and the shortlist; writes HTML, CSV, JSON and paper-portfolio files. On 23 Oct 2026: as of 2026-10-21, universe 300, liquid 256, ranked 181. Note: python -m us_stock_picks works only if the repo root is on the path.

Inspect the committed outputs without any data pull

python3 -c "import json;print(json.load(open('outputs/us_picks_latest.json'))['summary'])"

A dictionary with as_of, universe_n, liquid_n, ranked_n and sleeve_counts.

Limits and honest caveats

  • Not investment advice. This is mechanical screen output for research and education; screens fail in regime changes.
  • Data date: prices run to the 21 October 2026 session (the US panel has no 22 October bar) and fundamentals are Yahoo Finance values fetched on 23 October 2026. The cached price panel has missing sessions on many recent days, so Darvas boxes and moving averages on it are approximate.
  • The scan covered only the 300 most liquid US non-ETF stocks, built by an adapter, not the author's 5,800-stock scan. Quality and Actionable screens were missing, so ranks are not comparable with the committed July outputs.
  • Missing data silently counts as 'screen not passed': an earlier run with fundamentals missing for 162 names gave a different top 15. Per the README, the 'as of' date comes from the workbook filename, so I named it with the session date.
  • Extreme or contradictory fields pass through uncleaned, and conviction weights are the author's choices, not validated by any backtest in this repo.
