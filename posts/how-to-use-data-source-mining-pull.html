Why it is useful

  • Who benefits: analysts who want a macro panel for India and six comparison economies, or daily vegetable and grain market prices, without clicking through portals.
  • What it replaces: manual downloads from the World Bank site and data.gov.in.
  • Evidence from the run: a live call to the World Bank for India and Germany returned 326 rows for GDP growth, CPI inflation and renewable energy share in about a minute; one mandi API call returned records.
  • Result is a single DuckDB file you can query with SQL; the repo's committed copy (pulled 21 July 2026) has 4,532 World Bank rows and 4 mandi rows.
  • Small enough to read in five minutes, so you can add your own indicators.

What it is for

data-source-mining was written after an audit of a Claude usage log showed two open sources that were under-used: the World Bank API and Agmarknet daily mandi prices. The script mine_underused_sources.py pulls both and stores them in underused_sources.duckdb.

World Bank: 12 indicators (GDP, growth, inflation, agriculture share, fertiliser use, trade, energy mix, FDI, real interest rate, INR/USD) for IND, USA, CHN, BRA, DEU, JPN and KOR, paged through the public API.

Mandi: the data.gov.in Agmarknet resource, using the public sample key that data.gov.in documents, appended with a pulled_on date so a re-run on the same day replaces that day's rows.

Note on scope: the script mines a fixed pair of sources. It is not a general source-discovery search tool.

Who it is for

  • Economists and students who want a quick cross-country panel
  • Agri-trade and food-price analysts
  • Anyone learning DuckDB with real open data
Not for.
  • Investment decisions: this is raw open data, not investment advice
  • Real-time prices: mandi data is whatever the API returns on the pull day and the sample key is rate-limited
  • Running it inside the cloned folder if you want to keep the committed database: the script rebuilds worldbank_indicators with CREATE OR REPLACE in that file

Install

  1. Clone the repo
    git clone https://github.com/herrrickshaw/data-source-mining.git
cd data-source-mining
  2. Create a virtual environment and install DuckDB
    python3 -m venv .venv
.venv/bin/pip install duckdb

Quick start: commands and what you should see

World Bank only (about 84 API calls, a few minutes)

.venv/bin/python mine_underused_sources.py --wb-only

One line per country, then 'worldbank_indicators: N rows' and a table list. N was 4,532 in the committed 21 July 2026 pull.

Mandi prices only

.venv/bin/python mine_underused_sources.py --mandi-only

'mandi_prices: N rows pulled today'. The data.gov.in sample key returns a small sample, not the full market.

Query the result

.venv/bin/python -c "import duckdb; c=duckdb.connect('underused_sources.duckdb', read_only=True); print(c.sql(\"select country, round(value,2) as v from worldbank_indicators where indicator='gdp_growth_pct' and year=2024\"))"

GDP growth by country for 2024.

Limits and honest caveats

  • Not investment advice. These are raw open statistics.
  • Only the World Bank leg was run end to end here, on a reduced set (2 countries, 3 indicators) in a throwaway database; the full 7 x 12 pull and the full mandi pull were not re-run. Table sizes quoted come from the committed 21 July 2026 file.
  • Running the script in the repo folder overwrites worldbank_indicators in the committed underused_sources.duckdb. Copy the folder first if you want to keep it.
  • The README in the repo is only a placeholder pointing to a how-to-use page; the docstring in the script is the real documentation.
  • Mandi data from the sample key is small and the committed table has 4 rows; do not draw market conclusions from it. The World Bank latest year varies by indicator (renewables was 2021).
