Why it is useful

  • Analysts, journalists and students who need market-level (not just state-average) Indian crop prices get a daily history without paying for a data feed or registering for a portal.
  • It replaces hand-downloading Agmarknet pages: one script pulls the day, one table keeps the history, and re-running a day replaces that day instead of duplicating it.
  • The repo already ships CSV snapshots, so the demo needed no network at all: 463,023 rows across 21 Jul to 24 Sep 2026 loaded and queried in seconds.
  • The run also showed a trap worth knowing: a naive commodity-average day-on-day comparison put 'Wood' at -39.8%, while a like-for-like market comparison showed prices essentially flat. The post shows both.

What it is for

agri-commodity-tracker collects APMC mandi prices (state, district, market, commodity, variety, minimum, maximum and modal price in rupees per quintal) and a cross-country agriculture indicator panel from open sources, and writes them to data/agri.duckdb. Committed CSV snapshots let you explore the data without running any collector.

It also has collectors for the FCI depot directory, FAOSTAT producer prices and crop production, and NASA POWER monthly rainfall and temperature for 14 Indian states.

Who it is for

  • Analysts and researchers studying Indian food price behaviour
  • Students learning DuckDB on a real dataset
  • Developers building commodity dashboards or alerts
Not for.
  • Trading decisions: this is not investment advice, and prices are mandi spot prices, not futures
  • Complete daily coverage: some days are partial (see limits)
  • Official statistics: the data is as served by the source portals, unaudited

Install

  1. Clone and enter the repo
    git clone https://github.com/herrrickshaw/agri-commodity-tracker.git
cd agri-commodity-tracker
  2. Create a virtual environment and install dependencies
    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt pytest

Quick start: commands and what you should see

Run the test suite

python -m pytest -q

10 passed in about 5 seconds.

Collect today's mandi prices (live; needs network, slow with the demo key)

python3 collectors/mandi_prices.py

Rows are written to data/agri.duckdb, replacing any earlier pull for the same date. Not run in this demo, see limits.

Explore the committed snapshot without any network, with DuckDB

python3 -c "import duckdb; print(duckdb.sql(\"select pulled_on, count(*) n, count(distinct commodity) commodities from read_csv_auto('data/mandi_prices_snapshot.csv') group by 1 order by 1 desc limit 3\"))"

A table of the latest pull dates with row and commodity counts.

Limits and honest caveats

  • Not investment advice. Mandi spot prices only.
  • I did not run the live collector: collect.log in the repo ends with an HTTP 429 (Too Many Requests) from the source, and the public demo key serves 10 records per request, so a full pull is slow. Everything shown comes from the committed snapshot and the test suite.
  • The snapshot ends on 24 Sep 2026 (pulled dates 21 Jul to 24 Sep 2026), so it is not current as of the post date.
  • Per the README, days before 23 Jul 2026 are roughly 10-row stubs because of an earlier pagination bug and cannot be backfilled; the source only serves the current day.
  • Daily row counts and state coverage vary, so averages across days mix different market sets. Use like-for-like comparisons.
  • The data is as published by Agmarknet via data.gov.in and has not been audited.
